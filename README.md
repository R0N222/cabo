# Cabo

Das Kartenspiel Cabo mit Skatblatt – im Browser, online mit Freunden.
Spiel erstellen, Link schicken, fertig. Deutsch & Englisch.

The Cabo card game with a 32-card Skat deck, playable in the browser with friends via a shared link.

- Peer-to-peer multiplayer (PeerJS / WebRTC), the host's browser runs the game
- 2–6 players, bots to fill seats
- No build step: plain HTML/CSS/JS

Local testing: `node serve.js` and open http://localhost:5173
